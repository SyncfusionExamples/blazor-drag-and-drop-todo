# Blazor Drag & Drop Todo

A modern, interactive todo application built with Blazor WebAssembly App and [Syncfusion<sup style="font-size:70%">&reg;</sup> Blazor components](https://www.syncfusion.com/blazor-components), featuring seamless drag-and-drop functionality using HTML5 APIs and JavaScript interop.

## Overview

This project demonstrates how to build an interactive todo application with **drag-and-drop functionality** using:

- **HTML5 Drag and Drop API** for smooth, native drag operations
- **JavaScript Interop** for seamless C# and JavaScript communication
- **Syncfusion Blazor components** for polished UI elements
- **Blazor WebAssembly** for a performant, client-side experience

The application showcases best practices for integrating JavaScript interoperability in modern Blazor applications while maintaining clean separation of concerns.

## Features

- **Drag & Drop Tasks** - Intuitively reorder todo items with smooth drag-and-drop interactions
- **Mark Complete** - Move tasks to a collapsible "Completed" section
- **Responsive Design** - Works seamlessly on desktop and mobile devices
- **Syncfusion UI Components** - Professional-looking accordion and styling out of the box
- **Real-time Updates** - Instant UI updates using Blazor component state management
- **JS Interop** - Demonstrates practical C# and JavaScript integration patterns

## Getting Started

### Installation & Setup

### Clone the repository

```bash
git clone https://github.com/SyncfusionExamples/blazor-drag-and-drop-todo.git
cd blazor-drag-and-drop-todo
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
